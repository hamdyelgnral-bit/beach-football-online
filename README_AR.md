# Beach Football 3D — Online Starter

دي بداية تجهيز الأونلاين للعبة. المشروع يحتوي على:
- نسخة اللعبة الحالية داخل `public/index.html`.
- خادم Node.js + Socket.IO.
- إنشاء غرف بكود من 6 حروف/أرقام، والانضمام لغرفة، ورسائل حالة الاتصال.
- قناة لإرسال حالة المباراة من اللاعب المضيف، وقناة لمزامنة حركة اللاعبين.

## تشغيل الخادم على الكمبيوتر

1. ثبّت Node.js إصدار LTS.
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ:
   ```bash
   npm install
   npm start
   ```
4. افتح `http://localhost:3000`.

## مهم جدًا
هذه **نسخة تأسيسية للخادم** وليست إصدارًا نهائيًا مكتملًا للعب الجماعي. تم إعداد إنشاء الغرف ونقل الرسائل على الخادم، لكن يلزم ربط أزرار اللعبة وحركة اللاعبين والكرة بنتائج Socket.IO داخل كود اللعبة، ثم اختبار اللعب على جهازين. رفع الملفات وحده لا يكفي لتشغيل مباراة أونلاين كاملة.

## النشر
ارفع مجلد المشروع إلى استضافة تدعم Node.js و WebSocket (مثل Render أو Railway أو VPS)، ثم استخدم رابط الاستضافة لفتح اللعبة من الموبايل والكمبيوتر.
